# Woong

The working agreement lives in [`AGENTS.md`](AGENTS.md). Read it first, then
[`STATUS.md`](STATUS.md) and [`mvp/tasks.json`](mvp/tasks.json).

The five rules that cannot be broken, in short form:

1. No buy or sell recommendation, anywhere, ever.
2. No estimated, approximated or proxy number. A metric that cannot be computed
   to its real definition is switched off and says why.
3. No upstream provider names in code, comments, documentation, schema or
   interface. Sources are generic tags, connection details live in `.env`.
4. Python computes every number. The browser only presents.
5. Filter and rank stay separate stages.
